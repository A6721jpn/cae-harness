# FEBio CAE Harness V2

STEP部品に新規生成した剛体治具を接触させ、押し込みによる変形を解析するプロトタイプである。自然言語による条件設定、FEBio実行、XPLTプレビュー、部分編集と再解析の比較を対象とする。

V2は、独立した開発履歴を持つPython 3.12のheadless CLIである。ケース登録、明示的な条件設定・検証・固定、登録済み平面プロトタイプの実行、既存FEBio Studioセッションのプレビュー観測、限定的な比較や状態管理を実装している。操作方法と前提条件は[CLI使用ガイド](docs/cli-usage.md)を参照のこと。

任意のSTEPから解析までを、公開CLIのみで完結できる段階にはない。固定された合成ケース経路では実FEBio・Studioを用いた検証を行っているものの、一般的なネイティブ互換性、科学的・材料的妥当性、実モデルでの成功を保証するものではない。表面近似は`UNVERIFIED`であり、FB03における独立したformat 3検証も未完了である。最終BottomFrame実モデルのE2Eを含め、プロジェクトは開発・検証の途上にある。

## 開発とデータ境界

開発体制および検証手順は[開発契約](AGENTS.md)に準拠する。実部品の材料・荷重・拘束・接触・ROIなどの物理条件は、形状や慣例から推測せず、権威ある根拠に基づいて確定する。不足する必須条件は`ASK_AND_BLOCK`とする。

PM兼PdMはAstra X-high、実装は単独のAstra Low、独立レビューは別タスクのAstra Mediumが担当する。PM兼PdMが、承認済み要求における優先順位・実装範囲・技術方針・受け入れ基準・有限予算を決定する。テストと追加機能は計画達成に必要な最小限にとどめ、レビュー済みの小さな変更を順次統合する。

実CAEモデル・結果・認証情報はGitに含めない。公開先は[GitHubのV2ブランチ](https://github.com/A6721jpn/cae-harness/tree/V2)であり、状態は`REMOTE_CONFIGURED`である。既存CAE Harnessの資産はV2へ引き継がない。
