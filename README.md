# FEBio CAE Harness V2

STEP部品に新しく生成した剛体治具を接触させ、押し込みによる変形を解析するプロトタイプ。自然言語による条件設定、FEBio実行、XPLTプレビュー、部分編集と再解析比較を対象とする。

V2は独立した開発履歴を持つPython 3.12のheadless CLI。ケース登録、明示的な条件設定・検証・固定、登録済み平面プロトタイプの実行、既存FEBio Studioセッションのプレビュー観測、限定的な比較・状態管理を実装している。操作方法と前提条件は[CLI使用ガイド](docs/cli-usage.md)を参照。

任意のSTEPから解析までを公開CLIだけで完結できる段階ではない。固定した合成ケース経路では実FEBio・Studioを使用した検証があるが、一般的なネイティブ互換性、科学的・材料的妥当性、実モデルの成功を保証しない。表面近似は`UNVERIFIED`、FB03の独立したformat 3検証も未完了。最終BottomFrame実モデルE2Eを含め、プロジェクトは開発・検証中。

## 開発とデータ境界

開発体制・検証手順は[開発契約](AGENTS.md)に従う。実部品の材料・荷重・拘束・接触・ROIなどの物理条件は、形状や慣例から推測せず、権威ある根拠で確定する。不足する必須条件は`ASK_AND_BLOCK`とする。

実CAEモデル・結果・認証情報はGitへ含めない。公開先は[GitHubのV2ブランチ](https://github.com/A6721jpn/cae-harness/tree/V2)、状態は`REMOTE_CONFIGURED`。既存CAE Harnessの資産はV2へ引き継がない。
