## Implemented contract

- `Budget` is an immutable, slot-based value with all five required fields explicit: `max_elapsed`, `max_attempts`, `cpu_workers`, `max_llm_calls`, and `max_llm_tokens`. `SCHEMA_VERSION` is the existing canonical version `"1"`; `BudgetValidationError` is the dedicated validation exception.
- `max_elapsed` must be a strictly positive, finite `Quantity` with the time dimension. It is converted to total SI form at construction, so equivalent time units have identical canonical bytes and nonrepresentable overflow/underflow is rejected.
- `max_attempts` and `cpu_workers` are strictly positive integers. `max_llm_calls` and `max_llm_tokens` are nonnegative integers; boolean values, floats, strings, `None`, and negative values are rejected. Zero is explicit and retained as a disabled allocation, not treated as missing or unlimited.
- `to_dict()` contains the complete schema projection and `to_bytes()` delegates to the shared canonical owner. Construction canonicalizes the complete parent projection, rejecting integer counts beyond the shared JSON serialization digit boundary without changing interpreter limits or rounding to floats. Large serializable integer identity is preserved.
- No aliases, application accounting, clocks, subprocess handling, resource discovery, LLM provider, persistence, enforcement, concurrency reservation, physical `ASK_AND_BLOCK`, execution authority, or native solver claim is introduced by this slice.
