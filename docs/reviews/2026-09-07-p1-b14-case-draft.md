## Implemented contract

`PartialCaseSpec` is a frozen, slotted top-level composition of the eleven existing public child types: `geometry`, `material`, `support`, `rigid_tool`, `motion`, `contact`, `mesh_policy`, `solver_policy`, `outputs`, `quality_policy`, and `budget`. Each field defaults to `None`, where `None` means absence only; it does not invent physical or numerical values. Present fields are checked against their exact existing public child types, with field-specific validation diagnostics.

The value exposes sorted read-only `unresolved_fields`, detached `to_dict()`, and canonical `to_bytes()` through the shared child/canonical owners. Its schema-1 projection contains all eleven fields and complete public child projections for present children. `to_case_spec()` reports missing fields through `PartialCaseSpecValidationError`; when complete, it calls the existing `CaseSpec` constructor so cross-child consistency remains owned by `CaseSpec`. A complete conversion still does not certify evidence resolution or execution readiness.

`CaseDraft` is a frozen, slotted record with eight mandatory inputs: opaque `case_id`, opaque `draft_id`, integer `generation`, natural-language `input_intent`, paired optional `parent_revision_id`/lowercase SHA-256 `parent_spec_digest`, a `PartialCaseSpec` `values` snapshot, and an explicit sequence of existing `EvidenceRef` values. Omitted mandatory arguments retain generated-init `TypeError` behavior.

Identifiers preserve ordinary Unicode without normalization or case folding, reject empty/trimmed/control-containing values, and require UTF-8 representation. Parent metadata is all-or-none; parent existence and case membership remain later registered checks. `generation` excludes `bool` and must be nonnegative. `input_intent` preserves exact UTF-8 text, including spaces and newlines, and may be empty for an initial draft. Evidence is copied to an immutable tuple, rejects strings/bytes/mappings and wrong members, rejects exact complete canonical duplicates, and is canonically ordered through the shared owner. The record provides detached exact-key `to_dict()` and canonical `to_bytes()` projections and delegates `unresolved_fields` to `values`.

Neither value adds a digest, timestamp, registry, CAS, question-consumption rule, resolver, freeze service, `READY`/approved/success flag, or execution authority. A full values snapshot is distinct from a registered, evidence-verified ready state.
