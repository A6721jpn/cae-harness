# Bottom Frameスプリング 疲労・3年保持後復元評価レポート設計

## 目的と意思決定

完遂済みのBottom Frame解析を基礎に、剛体M2ネジで法線方向へ2.5 mm押されたABSスプリングについて、次の設計判断を支援する。

1. 変位付与・解放を90回繰り返したとき、疲労破壊の懸念が許容可能か。
2. 23 °Cで3年間（26,280時間）最終変位状態に保持した後、ネジ変位を解放したとき、機能上必要な位置へ戻ると判断できるか。

対象読者は機械設計者とする。成果物は日本語の自己完結型HTML技術レポートとし、計算・仮定・公表値・推論を区別する。

- 完遂解析結果：`C:\dev\FEBio\jobs\jobs\02_Bottom_Frame,0729_CAE.xplt`
- 完遂解析ログ：`C:\dev\FEBio\jobs\jobs\02_Bottom_Frame,0729_CAE.log`

- 疲労回数：90回
- 長期保持：23 °C、3年間

## 評価方式

### 完遂結果の短期評価

最終ステップから、少なくともフォンミーゼス応力、主ひずみまたは相当ひずみ、塑性状態、変位を抽出する。最大値だけでなく、発生位置と局所性を確認する。接触端、拘束端、低品質要素に限定されたピークは、その適用性を別途記述する。

### 解放解析

元の完遂入力は変更しない。派生FEBファイルを作り、同じ接触・境界条件・材料を維持したまま、剛体ネジ変位を2.5 mmから0 mmへ戻す解放ステップを追加する。解放後の残留変位と塑性ひずみを評価する。

この解析が表すのは、現行の時間非依存材料モデルによる短期除荷応答である。3年間の応力緩和、クリープ、物理時効を再現した結果とは扱わない。

### 疲労評価

90回は高サイクルS-N寿命予測ではなく、低回数の変位制御繰返しとしてスクリーニングする。次を確認する。

- 最終負荷時の局所ピーク応力・ひずみ
- 塑性変形の有無と範囲
- 解放後の残留変位
- 参照レポートの暫定基準との比較
- 成形品疲労データおよび温度依存性の適用限界

現モデルに疲労損傷則がないため、90サイクルを解析で回しても疲労き裂寿命の保証にはならない。必要に応じて、代表的な完全解放条件として平均応力と応力振幅を示す。

### 23 °C・3年保持後の復元評価

現材料カードには粘弾性・クリープ特性がない。したがって、公開一次資料とグレード固有データの有無を確認し、次の三段階で判定する。

- **短期復元**：派生除荷解析から計算可能
- **3年保持後の傾向**：公表されたABSのクリープ・応力緩和・回復データから範囲またはリスクとして評価
- **製品合否**：グレード固有長期データまたは実成形品保持試験がなければ未確定

## 暫定判定基準

参照レポートに合わせ、以下は設計スクリーニング基準としてのみ用いる。

- 局所ピークひずみ：1.0%以下
- 局所ピーク応力：22.5 MPa以下（公開代表降伏応力45 MPaの50%）
- 90回後：き裂、白化、機能喪失がない
- 解放24時間後の残留変位：最小掛かり余裕の20%以下

最小掛かり余裕が不明な場合、復元量は数値で示すが、機能合否は未確定とする。短期FEA値をそのまま3年後の値として使わない。

結論は「予備合格」「予備不合格」「未確定」を用いる。解析が正常終了したこと、メッシュが二次要素であること、短期非線形応答が得られたことは、疲労寿命や3年後復元の検証完了を意味しない。

次の情報が不足する場合は未解決項目として明示する。

- 最小掛かり余裕および許容残留変位
